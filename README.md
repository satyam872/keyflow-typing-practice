# ⌨️ KeyFlow - Typing Practice & SSC Exam Simulator

**KeyFlow** is a web-based typing practice platform designed to help users improve their typing speed, accuracy, and confidence. It offers progressive typing lessons, timed practice sessions, and an SSC Exam Simulator with different exam-specific typing modes.

Whether you are a beginner learning touch typing or preparing for an SSC typing test, KeyFlow provides a simple and interactive practice environment.

## ✨ Features

### 1. Progressive Typing Practice
- 10 progressive typing levels.
- Beginner to advanced typing exercises.
- Level-specific practice sentences and passages.
- 10-minute practice sessions.
- Fresh passages as you complete each exercise.
- On-screen virtual keyboard.
- Live typing performance tracking.

### 2. SSC Exam Simulator
Prepare for different SSC typing tests with dedicated practice modes:

| Exam Mode | Practice Duration | Reference Target |
|---|---:|---:|
| SSC CHSL LDC/JSA English | 10 minutes | 35 WPM |
| SSC CHSL LDC/JSA Hindi | 10 minutes | 30 WPM |
| SSC CGL DEST | 15 minutes | 2,000 key depressions |
| SSC CHSL DEO | 15 minutes | 8,000 KDPH |
| SSC CHSL DEO Grade A | 15 minutes | 15,000 KDPH |
| SSC Selection Post | Custom | Custom target |

*Note: These are practice reference targets. Always check the latest official SSC notification for applicable exam requirements.*

### 3. Live Performance Tracking
- Typing speed (WPM).
- Accuracy percentage.
- Total keystrokes.
- Error count.
- Remaining time.
- Final performance report.

### 4. User-Friendly Interface
- Clean and modern design.
- Easy-to-use navigation.
- Virtual keyboard for practice.
- Responsive layout.
- Dedicated SSC Exam Mode button.

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start practising!

You can also open the project in **Visual Studio Code** and use the Live Server extension.

## 🔄 How to Update the Website

KeyFlow uses separate HTML, CSS, and JavaScript files, making it easy to modify and maintain.

- Edit `index.html` to change website content and structure.
- Edit `style.css` to change colours, fonts, layout, and design.
- Edit `script.js` to update typing passages, levels, timers, and simulator functionality.

If hosted using GitHub Pages, push your updated files to the GitHub repository to publish the changes.
